# 示例：交互式系统架构手册（Markdown 检索与属性层）

> 当前是底层 Markdown 视图（供编辑 YAML 属性、维护双链以及供 Obsidian `Cmd/Ctrl + Shift + F` 全局全文检索）。点击右上角标题栏的 **🌐 地球图标** 或直接点击上方属性栏中的 `html` 链接即可切回 **全屏网页视图**。

## 核心检索摘要

- **核心机制**：以标准 `.md` 文件承载 YAML frontmatter（`status`、`tags`、`summary`、`html`）与高密度文字摘要；点开笔记时由 `HTML Note View` 自动接管标签页，零边距 100% 铺满渲染关联的交互式 `.html` 附件。
- **为什么不用裸 `.html`**：Obsidian 官方 `Bases`（`.base` 数据库视图）在内核层硬判断 `file.extension === "md"`，裸 `.html` 文件无法展示笔记属性与标签列。
- **内置桥接能力**：自动同步 Obsidian 深浅色主题（`<html data-theme="dark|light">`）、右上角注入可折叠状态与标签胶囊栏、接管 `#anchor` 目录平滑跳转与外链浏览器打开。
